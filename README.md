# MERN Stack Twitter Clone

  A full-stack web application similar to Twitter, built using MERN stack (MongoDB, Express, React, Node.js). This project allows users to sign up, post tweets, follow others, like/comment on tweets, and interact with a dynamic, responsive interface.

## 🚀 Project Inspiration

  This project is inspired by the YouTube channel "As a Programmer". You can check out their channel for more insightful tutorials and inspiration for building similar projects.


## Features

- User Authentication: Users can sign up, log in, and manage their profiles using JWT (JSON Web Token) for secure authentication.
- Post Tweets: Users can post tweets with text content.
- Like and Comment: Users can like and comment on tweets.
- Follow/Unfollow Users: Users can follow and unfollow others to stay updated with their tweets.
- Responsive UI: The frontend is built using React.js and styled with TailwindCSS for a modern, responsive design.
- Data Fetching: Efficient data fetching with TanStack Query (React Query).

## Technologies Used

### Frontend:

- React.js: A JavaScript library for building user interfaces.
TailwindCSS: A utility-first CSS framework for styling.
TanStack Query (React Query): For efficient data fetching and state management.
Backend:

- Node.js: A JavaScript runtime used for the server-side logic.
Express.js: A web framework for Node.js to handle routing and API requests.
Database:

- MongoDB: A NoSQL database for storing user data, tweets, comments, and more.
Authentication:

- JWT (JSON Web Token): Secure user authentication.
